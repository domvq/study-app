      How it works

      1. Step 1 — Open any topic: type it, paste notes, or upload a .txt / .md / .pdf document.
      2. Step 2 — Pick a game: Flashcards, Match, Quiz, Slideshow, and more — all built from the same confirmed material.
      3. Step 3 — Play anywhere: laptop, tablet, or phone. Short rounds fit your day, with scores, streaks, and instant feedback.

      Before any game is built: StudyAI searches Wikipedia and arXiv, asks follow-up questions if results are thin, and shows you a summary to confirm is correct. Only then does it generate the pack, which you can export as Markdown.

      Backend

      The backend (backend/server.py) is modelled on your Groq reference: same model (openai/gpt-oss-120b), same GROQ_API_KEY, same prompt-truncation and JSON-cleaning helpers, plus arXiv search. It needs no pip packages. Set GROQ_API_KEY in backend/.env (see backend/.env.example) and run python3 backend/server.py. GitHub Pages serves only static files, so host the backend separately and paste its URL in Settings above if you deploy the frontend to Pages.
